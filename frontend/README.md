# Childcare Benefit — Frontend

React + Vite + TypeScript app. See the repository root `README.md` for
setup and run instructions, and `ChildcareBenefit_Codex_Documentation/` for
requirements.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm run lint` — run Oxlint
- `npm run preview` — preview the production build locally
