# UI/UX Requirements

Build a modern, visually intuitive enterprise portal.

## Employee Dashboard
Show:
- Total allotted
- Approved
- In progress
- Remaining
- Children
- Recent claims
- Required actions

## Children
Responsive cards with child name, DOB, age, eligibility and benefit summary.

## Add Child
Capture child name and DOB.
Before save, show eligibility preview: FY, start, end, eligible months, monthly amount and total.

## Claim
Guided flow:
1. Select child
2. Invoice details
3. Upload documents
4. Eligibility preview
5. Review
6. Submit

## HR
Review employee, child, invoice, eligibility and documents in one screen.
Show approved amount input and Approve/Reject/Send Back actions.

## Responsive
Desktop sidebar.
Mobile navigation.
Tables become cards or safe horizontal layouts.
